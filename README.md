# 這個家，我話事！

栗子的犯案筆記：兩隻貓、一個家的 3D 搗蛋遊戲。

遊戲網站：https://cat-house-mischief.mickani.chatgpt.site/

## 本機執行

在專案目錄執行 `python3 -m http.server 8000 --directory dist`，然後開啟 http://localhost:8000 。請透過 HTTP 伺服器開啟，以便載入 JavaScript 模組及素材。

`dist/` 包含遊戲程式、圖片、音效及背景音樂；`tests/` 包含 Node.js 遊戲流程檢查，例如 `node tests/campaign.mjs`。

本儲存庫獨立於班級點數／Classroom 專案。
